

# 💫 About Me:
Hi, I’m Suyash Mishra, a frontend-focused Full Stack Developer passionate about building scalable, high-performance web applications with exceptional UI/UX.

I specialize in React.js, Next.js, JavaScript, Tailwind CSS, and modern component libraries, crafting interactive interfaces with clean architecture and user-centric design. Alongside frontend expertise, I’ve strengthened my backend skills with the MERN stack, working with Node.js, Express.js, MongoDB, Mongoose, and API design to build complete, production-ready applications.

Some of my key projects include KidsLe, an interactive learning platform for children, Digital Gallery, a full-stack artwork showcase platform, AI Mock Interview App powered by generative AI, and a Real-Time Collaborative Code Editor built using WebSockets and modern React patterns. These projects reflect my ability to design, develop, and deploy real-world solutions end-to-end.

Recently, I’ve been advancing my skills in DevOps and deployment workflows, working with Docker, CI/CD pipelines, GitHub Actions, and cloud deployments, enabling smoother development cycles and scalable production setups.

A quick learner with strong problem-solving skills and a collaborative mindset, I’m actively seeking opportunities as a Frontend / Full Stack Developer or Intern, where I can contribute to impactful products while continuously growing in system design, DevOps, and scalable architectures.
